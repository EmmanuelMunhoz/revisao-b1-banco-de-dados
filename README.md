## Recursos

- vídeos explicativos;
- exercícios organizados por módulo;
- revisão de erros;
- simulado geral;
- progresso salvo localmente no navegador;
- materiais em PDF;
- funcionamento responsivo e offline.

## Uso offline

Baixe a pasta completa e abra `ABRIR_REVISAO_BANCO.html` ou `index.html`. Não é necessário instalar programas nem iniciar um servidor.

## Privacidade

O progresso permanece apenas no navegador do aluno. O portal não possui login, analytics, trackers ou coleta de dados.

## Observação

Projeto educacional independente criado para apoio à revisão acadêmica.
